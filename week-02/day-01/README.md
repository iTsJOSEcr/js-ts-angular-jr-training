- Dominar los métodos más utilizados de los arreglos.
- Escribir código limpio y entendible.
- Resolver problemas utilizando JavaScript moderno.
- Prepararme para entrevistas técnicas.
- Construir una base sólida para Angular y TypeScript.

# Semana 2

## Día 1

### Métodos estudiados

- find()
- some()
- every()
- sort()
- Chaining

### Conceptos aprendidos

- Buscar elementos dentro de un arreglo.
- Verificar si existe al menos un elemento que cumpla una condición.
- Verificar si todos los elementos cumplen una condición.
- Ordenar números, strings y objetos.
- Encadenar métodos (`filter()`, `map()`, `sort()`).
- Uso correcto de operadores lógicos (`&&`).
- Diferencia entre `some()` y `every()`.
- Diferencia entre `find()` y `filter()`.

### Prácticas realizadas

- Búsqueda de usuarios.
- Productos con y sin stock.
- Validación de estudiantes.
- Ordenamiento por notas.
- Ordenamiento por precio.
- Chaining con múltiples métodos.
- Ejercicios con objetos y arreglos.
