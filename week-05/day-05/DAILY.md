# Week 05 - Day 05

## Tema

API Responses

## Temas estudiados

- Promise
- async y await
- ServiceResult
- ApiResponse
- Generics en respuestas
- Respuestas de éxito y error
- Arreglos y objetos asíncronos

## Lo aprendido

Aprendí que Promise indica qué tipo de dato obtendremos cuando termine una operación asíncrona.

También aprendí a utilizar async y await para trabajar con estas operaciones.

ServiceResult permite representar una operación que puede tener éxito o error.

ApiResponse permite crear una estructura reutilizable para las respuestas de una API.

También aprendí a combinar Promise, generics, objetos y arreglos para simular llamadas a una API.

## Práctica

Realicé ejercicios con usuarios, productos, cursos y empleados utilizando funciones asíncronas y respuestas tipadas.
