# Week 05 - Day 04

## Tema

Utility Types

## Temas estudiados

- Partial
- Pick
- Omit
- Record
- Required

## Lo aprendido

Aprendí que los Utility Types permiten modificar o reutilizar tipos existentes.

Partial permite hacer las propiedades opcionales.

Pick permite seleccionar solamente las propiedades que necesito.

Omit permite eliminar propiedades de un tipo.

Record permite crear estructuras de llave y valor.

Required permite convertir propiedades opcionales en obligatorias.

## Práctica

Realicé ejercicios individuales de cada Utility Type y luego prácticas mezcladas donde tuve que identificar cuál debía utilizar dependiendo del problema.
