# Week 05 - Day 04 - Utility Types

## Objetivo

Aprender a utilizar Utility Types de TypeScript para transformar y reutilizar tipos existentes de una forma más sencilla.

## Temas vistos

- Partial
- Pick
- Omit
- Record
- Required

## Utility Types

### Partial

Convierte todas las propiedades de un tipo en opcionales.

### Pick

Permite crear un nuevo tipo seleccionando solamente algunas propiedades de otro tipo.

### Omit

Permite crear un nuevo tipo eliminando determinadas propiedades.

### Record

Permite crear objetos definiendo el tipo de sus llaves y de sus valores.

### Required

Convierte todas las propiedades opcionales de un tipo en obligatorias.

## Práctica

Se realizaron ejercicios con empleados, productos, usuarios, cursos, vehículos, estudiantes, cuentas y configuraciones para practicar los diferentes Utility Types.

## Resultado

Se aprendió a identificar qué Utility Type utilizar dependiendo de la necesidad y a reutilizar tipos existentes sin tener que crear nuevas estructuras desde cero.
