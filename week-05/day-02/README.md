# Week 05 - Day 02 - Generic Constraints

## Objetivo

Aprender a utilizar Generic Constraints en TypeScript para limitar los tipos genéricos y exigir que los objetos tengan determinadas propiedades.

## Temas vistos

- Generic Constraints
- Uso de `extends` con generics
- Restricción de propiedades
- Constraints con una o varias propiedades
- Constraints mínimos

## Ejercicios realizados

- `getId`
- `getCode`
- `getName`
- `getEmail`
- `getPrice`
- `getActive`
- `getProductName`
- `getUserEmail`
- `getStock`
- `getUserId`
- `getEmployeeName`

## Resultado

Se crearon funciones genéricas utilizando `extends` para establecer requisitos mínimos en los objetos recibidos.

También se practicó cómo exigir una o varias propiedades y cómo evitar agregar propiedades innecesarias al constraint.
