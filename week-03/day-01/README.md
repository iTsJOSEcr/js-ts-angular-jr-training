## Semana 3 - Día 1

En este día se trabajaron los fundamentos de TypeScript:

- Tipos primitivos: `string`, `number` y `boolean`.
- Inferencia de tipos.
- Arreglos tipados.
- Union types.
- Objetos tipados.
- Funciones con parámetros tipados.
- Tipos de retorno explícitos.
- Funciones con retorno `void`.
- Parámetros opcionales.
- Uso de `undefined` en arreglos.
- Objetos dentro de arreglos.

También se completó una práctica de 10 ejercicios para convertir funciones de JavaScript a TypeScript.
