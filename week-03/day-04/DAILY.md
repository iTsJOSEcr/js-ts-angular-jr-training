# Semana 3 - Día 4

## Lo aprendido

Hoy aprendí a utilizar Union Literal Types para limitar los valores que pueden recibir las variables y funciones.

También comprendí que este tipo de datos ayuda a evitar errores de escritura y permite que TypeScript detecte valores inválidos durante el desarrollo.

## Temas practicados

- Union Literal Types.
- Funciones tipadas.
- Tipos de retorno.
- Restricción de valores.
- Operador ternario.
- Condicionales.

## Dificultades

Al inicio pensé que Union Literal Types solo servían para crear tipos con varios textos posibles. Después entendí que su verdadero objetivo es restringir los valores que pueden recibir las funciones y las variables, haciendo el código más seguro.

## Resultado

Se completaron todas las funciones solicitadas y una práctica final con 10 ejercicios utilizando diferentes tipos personalizados como Status, Role, Theme, PaymentStatus, Difficulty y HttpMethod.
