# Semana 3 - Día 2

## Lo aprendido

Hoy aprendí a utilizar `type` e `interface` para definir la estructura de los objetos en TypeScript.

También comprendí las diferencias principales entre ambos y cuándo es recomendable utilizar cada uno.

## Temas practicados

- Type Aliases
- Interfaces
- Objetos tipados
- Arreglos de objetos
- Union Types
- Funciones tipadas
- Propiedades opcionales
- Recorrido de arreglos con `for...of`

## Dificultades

Al principio tuve dificultad para comprender cómo crear arreglos de objetos (`Employee[]`), ya que olvidaba que cada elemento debía estar encerrado entre llaves `{}`. Después de practicar varios ejemplos, el concepto quedó claro.

## Resultado

Se completaron todos los ejercicios del día, incluyendo la creación de Type Aliases, Interfaces, comparaciones entre ambos y una práctica final aplicando todos los conceptos vistos.
