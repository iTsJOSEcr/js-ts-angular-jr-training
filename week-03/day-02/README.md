# Semana 3

## Día 2 - Interfaces y Type Aliases

### Temas vistos

- Type Aliases
- Interfaces
- Diferencias entre `type` e `interface`
- Union Types
- Objetos tipados
- Arreglos de objetos
- Funciones tipadas
- Propiedades opcionales

### Prácticas realizadas

- Creación de 5 Type Aliases.
- Creación de 5 Interfaces.
- Comparación entre `type` e `interface`.
- Uso de Union Types.
- Creación de funciones con objetos tipados.
- Uso de arreglos de objetos.
- Recorrido de arreglos con `for...of`.
- Práctica final con 8 ejercicios.

### Resultado

Se reforzó el uso de TypeScript para definir estructuras de datos reutilizables mediante `type` e `interface`, aplicándolos en funciones, arreglos y objetos.
