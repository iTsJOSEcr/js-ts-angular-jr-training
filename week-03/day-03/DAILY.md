# Semana 3 - Día 3

## Lo aprendido

Hoy aprendí a utilizar propiedades opcionales y parámetros opcionales en TypeScript.

Comprendí que el símbolo `?` permite indicar que un dato puede existir o no.

También practiqué el operador `??`, que permite colocar un valor por defecto cuando un dato es `null` o `undefined`.

## Temas practicados

- Propiedades opcionales.
- Parámetros opcionales.
- Operador `??`.
- Interfaces.
- Type Aliases.
- Funciones con tipos de retorno.
- Creación de objetos mediante funciones.
- Manejo de valores opcionales.

## Dificultades

Al principio me costó comprender el propósito de una función que crea y devuelve un objeto.

Después de realizar el ejercicio `createBook()`, entendí que estas funciones permiten reutilizar código y crear objetos de forma más sencilla.

También tuve dificultad con el cálculo de descuentos, porque inicialmente resté directamente el porcentaje al precio. Luego entendí que primero debía calcular el porcentaje del precio.
