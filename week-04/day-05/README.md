# Week 04 - Day 05 - Never

## Objetivo

Comprender el uso del tipo `never` para realizar verificaciones exhaustivas (Exhaustive Check) y garantizar que todos los casos posibles de un tipo sean manejados correctamente.

## Temas vistos

- Tipo `never`
- Exhaustive Check
- Validación de estados
- Manejo de errores con `throw`

## Archivos

- 01-never.ts
- 02-practice.ts

## Resultado

Se desarrollaron ejemplos utilizando `never` para verificar que todos los estados posibles de un tipo fueran manejados. También se comprobó cómo TypeScript detecta automáticamente cuando se agrega un nuevo estado y la función no ha sido actualizada.
