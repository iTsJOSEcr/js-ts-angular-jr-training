# Week 04 - Day 01 - Generics

## Objetivo

Aprender los fundamentos de los Generics en TypeScript para crear funciones e interfaces reutilizables con tipado seguro.

## Contenido

- Generic Type Parameters.
- Funciones genéricas.
- Generics con arreglos.
- Múltiples parámetros genéricos.
- Objetos genéricos.
- Interfaces genéricas.

## Archivos

- 01-generics.ts
- 02-functions.ts
- 03-practice.ts

## Resultado

Se desarrollaron múltiples funciones genéricas utilizando uno, dos y tres parámetros genéricos, además de interfaces genéricas para reutilizar tipos de manera más limpia y escalable.
